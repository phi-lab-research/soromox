# Examples

This directory contains small, self-contained demonstrations of SoRoMoX APIs.
Paper benchmarks and application studies live in [soromox-paper-experiments](https://github.com/phi-lab-research/soromox-paper-experiments),
where code, input data, and canonical outputs are versioned together.

## Layout

```text
examples/
├── simulation/                   # articulated, gvs, hsa, pcs, and pendulum
├── control/                      # actuation_space and operational_space
├── differentiation/              # kinematics, dynamics, and energy derivatives
├── data/                         # optional inputs shared by multiple topics
└── rendering/                    # Open3D and Viser presets and comparisons
```

An example writes generated figures or videos beside its script in `figures/`
or `videos/`. Artifact names begin with the script name so their provenance is
clear when several examples share a topic directory. These generated folders are
ignored by Git and are created on demand.

Use `examples/data/<dataset>/` only for committed inputs shared by examples in
more than one topic. Use `<topic>/data/` for committed topic-specific inputs or
for intermediate data generated by that topic; document whether each dataset is
an input or generated artifact in the example docstring or a topic README.

All built-in paths are resolved from the script location, so examples can be run
from the repository root or another working directory.

See [the Open3D and Viser preset example](rendering/README.md) for upright tapered soft
tentacles with pastel materials, a curved grey backdrop, lighting, and shadows.

Open3D simulation and control examples export trajectory videos through the modern
renderer to a `videos/` directory beside the script. Static Open3D views also use
modern rendering. Legacy animation previews are available through the renderer
API in a fresh process; mixing them with modern GUI windows on macOS is unsupported.

## Differentiation

`python examples/differentiation/derivative_modes.py` computes pose sensitivities,
a PCS state JVP, and total-energy gradients using default autodiff. To exercise
custom rules explicitly,
opt in explicitly with:

```bash
JAX_PLATFORMS=cpu python examples/differentiation/derivative_modes.py --custom-derivatives
```

The example selects its mode before tracing. See the
[Differentiation guide](../docs/user-guide/differentiation.md) for recommendations
covering kinematics, dynamics, and energies.
